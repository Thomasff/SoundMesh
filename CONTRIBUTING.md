# Contributing

SoundMesh is a personal side project. The author has limited time, so issues and pull
requests may take a while to get a response. Thanks for your patience.

## Issues

Bug reports are welcome, especially from handsets the project has not been tested on.
Please include:

- handset model and Android version
- what you did, step by step
- what you expected and what happened instead

If the problem involves synchronisation or calibration, please also say how many devices
were in the room and whether they were on WiFi or on a hotspot.

## Pull requests

- **Open an issue first for anything substantial.** It avoids work spent in a direction
  that will not be merged.
- **Changes to audio, synchronisation or calibration need verification on real hardware.**
  Unit tests cannot cover timing or how something sounds, so the author has to test these
  on devices before merging. That depends on when devices and time are both available, and
  it is the main reason a pull request may sit for a while.
- Small corrections (documentation, typos, clear logic errors) are usually handled quickly.
- Match the style of the code around your change. Comments in the codebase are written in
  English.

## Scope

There is no public roadmap. Feature suggestions are welcome as issues, but nothing is
promised.
