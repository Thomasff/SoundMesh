## 简介

多台安卓设备或 Windows 电脑接入同一局域网，一台作为主机提供音源，可播放**在线音乐/本地音乐**，其余设备自动加入并同步发声。除音乐外还可播放播客等任意声音，播放**存在 1 秒左右的播放延迟**，因此不适合音画同步要求高的场景（如游戏、视频）。

大多方案只靠网络同步，无法同步硬件上的延时，所以纯网络方案的设备间发声偏差通常大于数十毫秒。
本项目用声音互相校准测量硬件差距，对齐误差压到 0.5 ms 量级——大约是声音传播 17 cm 的时间，
而两个相同声音的时间差超过30ms才能被人耳区分。

本项目声学校准还可测出设备间大致距离，与高精度同步配合可进一步用于双声道分配、声像旋转与自定义声源位置等空间音效。

## 特性

- **高精度同步** —— 校准后设备间对齐误差约 0.5 ms。
- **自动测距** —— 声学测距量出设备之间的距离，配合高精度同步实现空间音效。
- **不限于本地文件** —— 可采集并分发本机正在播放的任意音频，包括各类在线音乐应用。
- **即开即用** —— 同一 WiFi 或热点下直接运行，电脑、手机可单独使用，也可混用，无需服务器或其他控制端。

## 使用场景

- **聚会与多人场合** —— 设备分散摆放，声场覆盖比单只音箱更均匀。
- **闲置设备再利用** —— 抽屉里的旧手机无需额外硬件即可组成一套音箱。
- **户外与临时场合** —— 露营、宿舍、出租屋等没有音响的环境，用在场设备就地组建。
- **空间音效** —— 多点摆位可实现单只音箱无法呈现的方位感与环绕感。

## 设备要求

| 项 | 要求 |
| --- | --- |
| 设备 | 2 台及以上，Android 10+（`minSdk 29`）或 Windows 10+，可混用 |
| 网络 | 同一 WiFi；或由其中一台安卓设备开启热点，其余接入 |
| 权限 | 安卓：麦克风（仅校准时使用）、通知、后台运行<br>Windows：麦克风（仅校准时使用，需 48 kHz），并在系统设置中打开「让桌面应用访问麦克风」 |
| 服务端 | 无需部署 |

## 快速开始

1. 安卓从 Releases 下载 apk 安装；电脑下载 `SoundMesh-版本-windows-x64.zip`，解压后运行其中的 `SoundMesh.exe`。电脑版无数字签名，首次运行若提示“Windows 已保护你的电脑”，点击“更多信息 → 仍要运行”。
2. 设备连接同一网络，一台选择"当主机"，其余选择"当从机"。从机通过自动发现或扫码连接主机；电脑当从机时不能扫码，可输入主机 IP。
3. 在主机上执行一次**位置同步校准**，需安静环境，耗时数十秒。
4. 选择音源，开始播放。

## 播放来源

| 来源 | 说明 |
| --- | --- |
| 单曲 | 选择本机的一个音频文件（电脑可多选） |
| 文件夹 | 连续播放整个文件夹，支持上一首 / 下一首 |
| 本机音频采集 | 采集本机正在播放的音频并分发至全部设备；电脑上可只采集指定程序 |

## 空间音效

测量得到的设备位置在此使用。

| 音效 | 说明 |
| --- | --- |
| 同步齐奏 | 所有设备播放相同内容，作为其余三档的对照 |
| 双声道 | 按实际摆位分配左右声道 |
| 旋转 | 声像绕房间转动，3 台及以上效果更明显 |
| 自定义声音位置 | 在房间图上拖动声源 |

## 同步原理

设备的音频输出链路存在延迟，该延迟随设备变化，仅靠网络对时只能对齐时钟，无法对齐实际发声时刻。SoundMesh 采用声学测量：
- **输出延迟** —— 设备播放信号并同步录音，由发声时刻与接收时刻之差解出本机输出延迟。
- **位置与时间** —— 各设备轮流发声、互相录音，由两两之间的声音飞行时间同时解出时间偏差与相对距离。

设备之间的单方向校准只需一次，校准后，设备间对齐误差约 **0.5 ms**，空气中 1 ms 约合 34 cm。每次可选择校准摆放位置以提供更好的效果。

未校准设备之间的偏差远超 0.5 ms，若要达到此精度，**不可跳过校准**。

## 已知限制

- 支持安卓与 Windows。**暂不支持 iOS、macOS 与 Linux。** 目前仅在有限机型上测试过，如遇问题欢迎反馈。
- **播放延迟约 1 秒，一般不适合用于看视频或电影。** 采集模式下安卓本机媒体音量被置 0，电脑上被采集程序的音量被调至极低（结束后恢复）。
- 部分手机受到系统省电机制影响，可能偶尔极短暂中断。
- 电脑无法开热点，热点模式下须由安卓设备开热点，电脑接入后仍可当主机。
- 部分安卓设备采集模式采集的是本机全部媒体输出，而非指定应用；其他应用发声也会被分发。
- 电脑采集程序声音需 Windows 10 21H2 及以上。
- 音频格式限 16-bit PCM 立体声，采样率 8–96 kHz。
- 校准时要求环境较安静，且设备无遮挡。
- 未上架应用商店。安装包可在 Releases 下载，也可自行构建；电脑版未做代码签名。

## 构建

安卓端需本机已安装 JDK 17：

```bash
git clone https://github.com/Thomasff/SoundMesh.git
cd SoundMesh
./gradlew assembleDebug
```

Windows 使用 `gradlew.bat assembleDebug`。产物位于 `app/build/outputs/apk/debug/`。

电脑端需本机已安装 JDK 17 和 JDK 25：

```bash
./gradlew :desktop-app:createDistributable
```

产物位于 `desktop-app/build/compose/binaries/main/app/SoundMesh/`，自带 Java 运行时，运行其中的 `SoundMesh.exe`。

运行单元测试：

```bash
./gradlew test
```

## 架构

星形拓扑，从机之间不通信。

```mermaid
flowchart TD
    H["主机<br/>选曲 · 解码 · 授时"]
    H --> A["从机 A"]
    H --> B["从机 B"]
    H --> C["从机 C"]
```

每条连接承载两路：常驻命令通道（角色、音量、播放控制、在线状态）与音频流。
音频块提前约 1 秒下发，每块携带主机时钟上的目标发声时刻；从机换算至本地时钟后输出，
校准所得的输出延迟作为该换算中的一项。
